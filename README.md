# Análisis de Abandono de Clientes (Customer Churn Analysis)

## Contexto del Negocio
El abandono de clientes (churn) es uno de los problemas más costosos para las empresas modernas. Este proyecto analiza los datos de una empresa para descubrir por qué los clientes se están yendo y qué acciones estratégicas se pueden tomar para retenerlos.
